# Internship Web

หน้าเข้าสู่ระบบต้นแบบสำหรับระบบจัดการฝึกงาน อ้างอิงหน้า Student Login จาก Figma พร้อมปรับให้ใช้งานได้บนมือถือและคอมพิวเตอร์

ใช้ **Vue 3 + Vuetify 4 + Vue Router + Vite** สำหรับหน้าเว็บ และ **Express 5** สำหรับเซิร์ฟเวอร์ เขียนด้วย JavaScript แบบ ES Modules ฟอนต์ภาษาไทยรวมอยู่ในโปรเจกต์ ไม่เรียกจาก Google Fonts ขณะใช้งาน

## เริ่มใช้งาน

ติดตั้ง Node.js 22.12 ขึ้นไป (แนะนำ Node.js 22 LTS) แล้วรัน:

```sh
npm ci
npm run dev
```

เปิด <http://127.0.0.1:5173/login> โดย Vite ทำงานที่พอร์ต 5173 และ Express ที่พอร์ต 3000 คำสั่งเดียวเปิดทั้งสองส่วน และ proxy `/api` ไป Express

## รันเว็บหลัง build

หยุดโหมดพัฒนาด้วย Ctrl+C ก่อน เพื่อให้พอร์ต 3000 ว่าง จากนั้นรัน:

```sh
npm run build
npm start
```

เปิด <http://127.0.0.1:3000/login> Express จะให้บริการไฟล์ใน `dist/` และรองรับการเปิดลิงก์ `/login` โดยตรง หน้า `/` จะเปลี่ยนไป `/login` ผ่าน Vue Router

ค่าเริ่มต้นเซิร์ฟเวอร์รับการเชื่อมต่อที่ `127.0.0.1:3000` เปลี่ยนได้ด้วย environment variables `HOST` และ `PORT`

## สิ่งที่มีในรอบนี้

- ฟอร์มภาษาไทย พร้อมช่องอีเมลหรือรหัสนักศึกษาและรหัสผ่าน
- ตรวจช่องว่าง รวมถึงข้อความที่มีแต่ช่องว่าง โดยไม่บังคับช่องบัญชีให้เป็นรูปแบบอีเมล
- แสดง/ซ่อนรหัสผ่าน กด Enter ส่งฟอร์ม และใช้งานด้วยแป้นพิมพ์
- ตัวเลือกจดจำการเข้าสู่ระบบเป็นสถานะภายในหน้าจอ รีเฟรชแล้วจะรีเซ็ต
- ลิงก์ลืมรหัสผ่านและติดต่อผู้ดูแล เปิดกล่องข้อความให้คำแนะนำ ไม่ส่งข้อความออกไป
- หลังกรอกครบและกดเข้าสู่ระบบ จะแสดง “หน้านี้เป็นต้นแบบ ยังไม่เชื่อมต่อระบบเข้าสู่ระบบ”
- `GET /api/health` ตอบ `200` พร้อม `{ "status": "ok" }`; API อื่นตอบ `404`

**ยังไม่มีการยืนยันตัวตนจริง ฐานข้อมูล session หรือ API เข้าสู่ระบบ** ฟอร์มไม่ส่งข้อมูลบัญชีหรือรหัสผ่านผ่านเครือข่าย ไม่บันทึกลง storage และไม่เขียนข้อมูลเหล่านี้ลง console ตัวเลือกจดจำไม่ได้สร้าง session

## โครงสร้าง

```text
src/
  main.js               ตั้งค่า Vuetify และ router
  App.vue               โครงแอป
  views/LoginView.vue   หน้าจอและพฤติกรรมฟอร์ม
  styles.css            รูปแบบและ responsive layout
server/
  index.js              Express, health endpoint และ static server
vite.config.js          Vue, Vuetify และ development proxy
```

## ตรวจการทำงาน

1. รัน `npm run build` ให้ผ่าน และรัน `npm start`
2. เปิด `/login` ที่ความกว้าง 390 และ 1440 px ตรวจว่าฟอร์มไม่ล้นแนวนอน
3. ลองส่งฟอร์มว่างหรือมีแต่ช่องว่าง ต้องแสดงข้อผิดพลาด
4. กรอกอีเมลหรือรหัสนักศึกษาพร้อมรหัสผ่าน แล้วกด Enter ต้องแสดงข้อความต้นแบบ โดยไม่เปลี่ยนไปหน้าที่อ้างว่าเข้าสู่ระบบสำเร็จ
5. ตรวจปุ่มแสดง/ซ่อนรหัสผ่าน checkbox และกล่องข้อความช่วยเหลือทั้งสองแบบ
6. ใช้ Tab/Shift+Tab, Enter, Space และ Escape ตรวจลำดับโฟกัสและการปิดกล่องข้อความ
7. ตรวจ Network และ Console ว่าไม่มีข้อมูลฟอร์มถูกส่งหรือบันทึก และ storage ไม่มีรหัสผ่าน
8. เปิด `/api/health` ผ่าน Express และผ่าน Vite proxy ต้องได้ `{ "status": "ok" }`

ไม่มีการตั้งค่า hosting ในรอบนี้
